# Personal Portfolio Website

This repository contains the source for my personal portfolio website.

**Live site:** https://sergiov3005.github.io

Built with [Jekyll](https://jekyllrb.com/) using the excellent [sproogen/modern-resume-theme](https://github.com/sproogen/modern-resume-theme), where you find the guide for reproducibility and personalization of the template.

---

## Features

- Simple, single-page resume/portfolio
- Dark mode
- Project, Experience, Education, and Blog sections
- Easy config via `_config.yml`
- Deploys automatically with **GitHub Pages**
